# GNOME Wallpaper

[English](README.md)

Bing の写真で、毎日の壁紙を楽しむ GNOME 拡張です。壁紙を自動で切り替え、写真の名前と出典を上部パネルから確認できます。

**GNOME Shell 50** に対応し、ライト・ダークの両テーマで同じ写真を使います。

## できること

- 毎日の更新はおまかせ。好きなときに **Refresh now** で更新することもできます。
- 日本や米国などの地域と、UHD／1920×1080 の画像を選べます。
- ダウンロードに失敗しても、今の壁紙を保って自動で再試行します。
- 無効にすると元の壁紙に戻ります。自分で壁紙を変更していた場合は、その設定を保ちます。

## 使い始めるには

現在は開発初期の版です。自動テストは通っていますが、実際の GNOME 画面での動作確認はこれからです。確認が済んだら、リリースとインストール手順を用意します。

インストール後、拡張の管理画面で **Daily Wallpaper** を有効にすると、最新の写真を自動で取得します。

上部パネルの壁紙アイコンを開くと、写真の名前、出典、更新状況が見られます。**Refresh now** ですぐに更新し、**Preferences** から次の設定を変更できます。

- **Market**：Bing の地域。初期設定は日本の `ja-JP` です。米国なら `en-US` を指定します。
- **Resolution**：初期設定は UHD。1920×1080 も選べます。UHD が取得できないときは、Bing の通常画像を使います。

操作画面は英語で、写真の情報は選んだ地域に応じた言語になります。画像の取得にはインターネット接続が必要です。更新に失敗したときは、次の再試行を待つか **Refresh now** を選んでください。

## 保存した写真

写真は通常 `~/.local/share/gnome-wallpaper` に保存し、再利用します。古い写真は自動で整理しますが、壁紙に必要な写真は残します。拡張を無効にしても保存した写真は残ります。
